# Sistema Pet Shop

Sistema web para gerenciamento de pet shop com:
- Cadastro de clientes e pets
- Agendamento de serviços
- Controle de estoque

## Tecnologias
- Frontend: React
- Backend: Node.js + Express
- Banco: MySQL

---

Instruções rápidas de Git:

Para stagear todas as mudanças para commit:

```
git add .
```

Para commitar:

```
git commit -m "primeiro commit"
```

Para renomear a branch atual para 'main':

```
git branch -M main
```

Para enviar a branch main para o remoto e configurar o upstream:

```
git push -u origin main
```
